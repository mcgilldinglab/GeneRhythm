# GeneRhythm

GeneRhythm is a deep learning framework for studying temporal gene expression programs with wavelet-based time-frequency modeling. This documentation site is configured for Read the Docs and includes a browsable, non-executed view of all tutorial notebooks in the repository.

## Highlights

- Wavelet-based frequency extraction for gene expression dynamics
- Rhythmic gene clustering and biomarker discovery
- Support for single-cell, spatial, and perturbation analysis workflows
- Tutorial notebooks rendered as static documentation pages
